Agents

Every fetch of a page, the feed, the text files and the Markdown copies by anything that isn't a browser. A browser's own page fetches are counted apart; people are counted by the tracker, so the two numbers never add up to one total.

Requests

Every request the Worker answered: pages, the feed, the text files, redirects, 404s, the tracker's calls, the admin and its API. Pictures, fonts, CSS and JS under /assets/ and /blog/media/ never reach the Worker and are not here. A row marked ×N stands for N requests (Analytics Engine samples bursts). Times are UTC; the duration is the Worker's wait for the assets, the database or the SQL API.
