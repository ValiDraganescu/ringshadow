## Post

Quit Ringshadow and its world keeps going. The local server stays up on the Mac: the clock turns, meteors fall, the Foundry and the Lab finish their jobs and the bugs keep roaming. Start the game again and it reattaches.

Ringshadow is an open-source Mac game built by AI agents while I direct. Its online mode is one world that lasts.

With nobody connected the server ticks twice a second and costs about 0.008% of one CPU core. With a pilot in the world it runs at 60 steps a second, about 0.3 to 0.5%.
